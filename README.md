# FRAMBEG TECH 🚀

Frambeg Tech is a modern full-stack React e-commerce Single Page Application (SPA) designed to provide users with a smooth, fast, and intuitive online shopping experience. The platform features a responsive UI, real-time interactions, and secure authentication for both users and administrators.

---

## Features

- 🛍 User-friendly and responsive interface
- 📦 Product catalog with categories, search, and filtering
- 🛒 Shopping cart and smooth checkout process
- 🔐 Secure user authentication using JWT
- 🧑‍💼 Admin panel for managing products and orders
- ⚡ Fast Single Page Application (SPA) experience
- 📱 Mobile-friendly and responsive design
- 🧾 Order management system
- 🎯 Clean UI/UX design for better user experience

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/GANABA-25/Frambeg-Tech.git
cd Frambeg-Tech
```

---

### 2. Install dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd backend
npm install
```

---

### 3. Environment Variables

Create a `.env` file in the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

### 4. Run the project

#### Start Backend

```bash
cd backend
npm run dev
```

#### Start Frontend

```bash
cd frontend
npm start
```
